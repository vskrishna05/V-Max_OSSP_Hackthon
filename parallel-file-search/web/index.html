01. WORK QUEUE

Dynamic Work Queue

Uses a thread-safe linked-list queue (work_queue_t) protected by pthread_mutex_t. Worker threads sleep on pthread_cond_t (has_work) and wake instantly when directories are discovered.

02. SYMLINK SAFETY

Inode Cycle Protection

To prevent infinite recursion caused by circular symlinks, every visited directory's device and inode pair (dev_t, ino_t) is recorded in a mutex-guarded hash set.

03. CONTENT SCANNER

Streamed Text Matching

Inspects files line by line using getline. Employs binary file heuristic detection by scanning the first 1024 bytes for null characters and non-printable control bytes.

04. CONCURRENCY SHUTDOWN

Zero-Busy-Wait Termination

Termination is detected deterministically when count == 0 && active_workers == 0, broadcasting all_done to awaken and join all POSIX threads cleanly.

05. DEDUPLICATION

3-Tier Duplicate Engine

Eliminates redundant files by first sorting files by size in $O(N \log N)$ time, computing 64-bit FNV-1a hashes on size collisions, and verifying with byte-by-byte memcmp.

06. MONOTONIC TIMING

High-Precision Timers

Measures benchmark and search execution via clock_gettime(CLOCK_MONOTONIC) to provide nanosecond-accurate duration independent of system wall-clock changes.
